# SKU 制作台 Windows 使用说明

版本：0.1.3。适用系统：Windows 10/11 x64。

## 安装

1. 运行安装程序，按提示完成当前 Windows 用户的安装。
2. 按安装器提示准备 WebView2。
3. 首次打开时设置本机管理员账号，密码至少 8 个字符。
4. 通过首页账号入口管理普通用户。管理员和普通用户均可使用全部制作模板。
5. 通过公司授权渠道安装模板要求的 Montserrat 和方正兰亭字体。

## 制作与保存

选择模板新建，或打开 `.skuwork` 源文件。按模板上传图片、填写型号和尺寸，在画布调整产品与标注，保存源文件后导出 JPG。

有内容的制作保存在临时现场，保存源文件后进入最近源文件。源文件包含图片和编辑状态，可用于换电脑、继续制作和协作交接。

每份源文件使用独立窗口，相同文件再次打开时激活已有窗口。各窗口独立保存与关闭。发生外部文件修改冲突时，按提示另存。

白底图片处理使用本机 Photoshop 2020 或更高版本，并自动识别当前运行或注册的版本。透明素材可直接导入。

## 升级与数据

升级前保存工作并关闭全部制作台窗口，再运行同一应用标识的新版安装程序。源文件位于用户选择的位置，账号与草稿位于当前 Windows 用户的应用数据目录。

安装文件的完整性可用随附 SHA256 核对。
